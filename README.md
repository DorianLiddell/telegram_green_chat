# Telegram GREEN-API Chat

Минимальный web-интерфейс для отправки и получения текстовых сообщений Telegram через GREEN-API.

## Стек

- React
- TypeScript
- Vite
- Native Fetch API
- CSS

## Возможности

- подключение к GREEN-API;
- проверка состояния Telegram-инстанса;
- создание нового чата по номеру телефона;
- получение `chatId` через `CheckAccount`;
- получение информации о пользователе;
- загрузка истории сообщений;
- отправка текстовых сообщений;
- получение входящих текстовых сообщений;
- автоматический long polling;
- удаление обработанных GREEN-API notifications;
- адаптивный интерфейс.
